# Zylo CRM — Version Changelog

All notable changes to the Zylo CRM codebase are documented in this file.

---

## [1.0.0] - 2026-07-30

### Release Highlights
- **Production Launch**: Complete release of Zylo CRM enterprise suite.

### Added
- **Authentication**: Email/Password Sign-In, Password Reset, and Supabase Session Sync.
- **Dashboard Shell**: Responsive sidebar navigation, top header, user menu dropdown, and mobile menu drawer.
- **CRM Module**: Leads pipeline management, status/priority filters, deal value estimation (₹), and CRUD dialogs.
- **Clients Module**: Client account directory, lifetime spend analytics, and client detail dialogs.
- **Projects Module**: Project milestone progress tracking, status badges, and budget allocation.
- **Tasks Module**: Kanban Board, List Table, Calendar View, Subtask Checklists, and Overdue Widgets.
- **Finance Module**: Invoices, Quotations, Convert Quote to Invoice, Expense Tracking, and Printable PDF Slips.
- **HR Module**: Employee Directory, Departments, Attendance Logger, Leave Requests, and Monthly Payroll Slips.
- **Reports Module**: Executive Analytics, Timeframe Filters (*Weekly, Monthly, Yearly*), SVG Funnel Charts, and Multi-Format Exports.
- **Settings Module**: Organization Profile, App Theme, Email Templates, DB Backup & JSON Restore, and Audit Logs.
- **RBAC Module**: Role-Based Access Control matrix, System & Custom Roles, and User Role Assignment.
- **Notifications Module**: Live Unread Counter Bell, Realtime Supabase Channel Listener, Popover Dropdown, and Preferences Dialog.
- **Indian Rupee (₹) Localization**: Full `en-IN` number formatting (`₹1,25,000`) across all monetary metrics.
- **Branding Assets**: Official logo (`logo.png`) and mascot (`mascot.png`) integrated into auth screens, dashboard welcome banner, and empty state tables.
